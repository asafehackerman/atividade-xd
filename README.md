Após clonar o projeto: 

1) Dentro da pasta Adonis-back, executar:

    cd Adonis-back

    npm install

    configurar dados banco - arquivo ".env"

    node ace migration:fresh --seed

    node ace serve --hmr
    
2) Dentro da pasta React-front, executar: 

    cd React-front

    npm install
    
    npm run start
